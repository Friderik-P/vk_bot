## v0.0.1 (Beta)

**Дата:** 2026-09-09  
**Статус:** Beta — ранний доступ, возможны изменения API и поведения.

### 🎉 Что нового

Первый публичный релиз VK-GigaChat Bot с базовым набором функций:

- **Интеграция с GigaChat** — генерация ответов, обработка ошибок, fallback на простые триггеры.
- **Long Poll сервер** — маршрутизация сообщений, админ-команды, антиспам, лимиты.
- **18+ и контекстный фильтры** — жёсткий/мягкий уровни, нормализация текста, поддержка транслитерации и обхода пробелов.
- **Рассылка сообщений** — автоматическая по расписанию, retry при rate limit, игнор-лист.
- **Планировщик задач** — рассылка каждые 24 часа, health-check GigaChat каждые 10 минут, очистка истории по понедельникам.
- **Админ-панель** — `/health`, `/stats`, `/admins`, `/admin_add`, `/admin_del`, `/delete_db`, `/stop`, `/restart`.
- **История диалогов** — сохранение переписки, статистика, prune по лимиту записей.
- **Запрос прав администратора** — пользователи могут запросить права фразами «права администратора» / «права администраторв».

### ⚠️ Известные ограничения Beta

- GigaChat может возвращать таймауты при высокой нагрузке; клиент умеет повторять запросы.
- Фильтры работают на основе статических списков слов; возможны ложноположительные срабатывания.
- Админ-файл `admins.yaml` создаётся автоматически; резервное копирование не реализовано.
- В рассылке используется фиксированное сообщение; кастомизация через код.
- Нет тестов — оверрайт и покрытие будут добавлены позже.

### 🚀 Быстрый старт

```bash
python -m venv venv
.\venv\Scripts\activate   # Windows
source venv/bin/activate  # Linux/macOS
pip install -r requirements.txt
```

Создайте `.env`:

```dotenv
VK_API_TOKEN=ваш_токен
VK_GROUP_ID=id_группы
GIGACHAT_AUTH_KEY=Bearer ваш_ключ
ADMIN_IDS=000000000,000000000
SERVER_NAME=MyVKBot
```

Запуск:

```bash
python main.py
```

Подробности — в [README.md](README.md) и [CONTRIBUTING.md](CONTRIBUTING.md).

### 🛠️ Технические детали

- **Python:** >= 3.10
- **Хранение:** SQLite с WAL-режимом, thread-local соединения, retry при блокировках.
- **Логирование:** RotatingFileHandler, уровни INFO/ERROR, папка `logs/`.
- **Зависимости:** `vk-api`, `gigachat`, `schedule`, `python-dotenv`, `requests`.

## v0.0.2

**Дата:** 2026-09-09  
**Статус:** Beta — архитектурный рефакторинг, тесты, защита от утечек.

### 🎉 Что нового

#### Добавлено
- **Тесты pytest** — 73 теста для конфига, админов, БД, спам-трекера и фильтров; покрытие ключевых модулей 80%+
- **Audit log** — таблица `admin_audit` в БД для логирования всех админ-действий
- **Graceful shutdown** — корректное завершение работы по SIGINT/SIGTERM с закрытием соединений
- **Защита от переназначения имён** — детектор атак вида "зови тебя X" + "кто создал X?"
- **Защита от случайного удаления БД** — убрана кнопка `/delete_db` из инлайн-клавиатуры
- **Бэкап БД** — автоматическое создание `.db.backup` перед удалением
- **Константы** — модуль `src/constants.py` сmagic numbers/strings
- **Единый `notify_admins()`** — утилита для уведомления админов вместо дублирования кода
- **Валидация `user_id`** — строгая проверка диапазона (1..9999999999) для `/admin_add` и `/admin_del`
- **Документация** — `RELEASES.md` с детальным changelog

#### Изменено
- **Конфигурация** — убрана двойная загрузка `.env`; `Settings` dataclass с ленивой загрузкой
- **Архитектура** — рефакторинг `Server` на `AdminCommandHandler`, `MessageRouter`, `Bot` protocol
- **Инкапсуляция** — глобальное состояние вынесено в классы: `SpamTracker`, `AdminStore`, `GigaChatService`
- **Пул соединений** — заменён busy-wait на `threading.Condition` в `ConnectionPool`
- **Спам-трекер** — добавлены `deque(maxlen=200/100)` для ограничения памяти
- **Команда `/admins`** — показывает кликабельные ссылки на профили VK
- **Системный промпт** — добавлен запрет на раскрытие информации о создателе
- **Контекстный фильтр** — расширен фразами про создателя, Сбер и ГигаЧат
- **Комментарии** — стандартизированы на русский язык
- **Зависимости** — добавлены `pyyaml`, `httpx`, `pytest-cov`, `black`, `flake8`, `mypy`

#### Исправлено
- **Обработка сигналов** — `_shutdown()` больше не вызывает `sys.exit()`, использует `threading.Event`
- **Дублирование `_cleanup()`** — убрано из `_shutdown()`, оставлено только в `finally`
- **Импорт-сайд-эффекты** — убрана загрузка конфига при импорте `src/config.py`
- **Type hints** — добавлены аннотации типов в `server.py`, `handlers/message.py`, `handlers/callback.py`
- **Магические строки** — вынесены в `prompts.py` и `constants.py`
- **Циклические импорты** — устранены через `Protocol` и `TYPE_CHECKING`
- **Обработка ошибок** — добавлены try/except в критических местах с логированием

### 🔒 Безопасность

- **Защита от утечек** — системный промпт запрещает раскрывать создателя/разработчика
- **Пост-фильтр ответов** — проверка ответов LLM на фразы о создателе
- **Audit trail** — все админ-команды логируются с `admin_id`, `peer_id`, временем
- **Бэкап перед удалением** — защита от случайной потери данных
- **Валидация входных данных** — проверка диапазона `user_id` и типов аргументов

### ⚠️ Известные ограничения

- SSL-проверка для GigaChat отключена (`verify_ssl_certs=False`) — планируется включение в следующем релизе.
- Покрытие тестами ~52% по строкам; ключевые модули (config, admins, spam, filters) покрыты на 80%+.
- Нет миграций БД — schema версионируется через `init_db()`.
- Контекстный фильтр работает по статическим спискам; возможны ложноположительные срабатывания.

### 🚀 Миграция с v0.0.1

1. Установите новые зависимости: `pip install -r requirements.txt`
2. Проверьте `.env` — все переменные совместимы
3. При первом запуске `admins.yaml` создастся автоматически из `ADMIN_IDS`
4. База данных `bot.db` автоматически обновится при старте (новые таблицы `admin_audit`)
5. Старые данные пользователей и истории сохранятся
